Mathematical Foundation: Why Simple RNN Struggles with Long Sequences
Theoretical Rigor
Simple RNN: The Vanishing Gradient Problem

In Simple RNN, state update is: \( h_t = \tanh(W_{hh} h_{t-1} + W_{xh} x_t) \). During Backpropagation Through Time (BPTT), the gradient of loss \( L \) at step \( T \) with respect to hidden state \( h_1 \) is:

∂L / ∂h_1 = (∂L / ∂h_T) × ∏_{k=2}^T (∂h_k / ∂h_{k-1}) = (∂L / ∂h_T) × ∏_{k=2}^T [ \text{diag}(1 - \tanh^2(...)) × W_{hh}^T ]

Since \( \tanh' \le 1.0 \), if the eigenvalues of \( W_{hh} \) are less than 1, the gradient diminishes exponentially with sequence distance \( (T - 1) \). The network completely forgets sentiment cues occurring early in long text sequences.

LSTM: The Constant Error Carousel (CEC) Solution

LSTM decouples the hidden state from the memory conveyor via the additive Cell State \( C_t \):

C_t = f_t ⊙ C_{t-1} + i_t ⊙ \tilde{C}_t  &implies;  ∂C_t / ∂C_{t-1} = f_t

When the Forget Gate \( f_t \approx 1.0 \), the error gradient propagates backward across hundreds of time steps with zero exponential decay. This allows the model to preserve early sentiment and resolve distant negations.
