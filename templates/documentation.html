1. Abstract & Problem Statement

Problem Statement: "Sentiment Analysis using RNN/LSTM: Implement an RNN and an LSTM on a text sequence dataset; compare their ability to capture long-term dependencies."

This research implements an end-to-end deep learning framework designed to investigate the fundamental operational trade-offs between standard First-Order Recurrent Neural Networks (Simple RNN) and Gated Memory Networks (LSTM) in binary sentiment classification. Using 50,000 polar reviews from the benchmark IMDB corpus, both models are trained under identical tokenization, sequence lengths, and hyperparameters to evaluate test accuracy, precision, recall, ROC-AUC, training throughput, and distance-decay vulnerability.

2. System & Model Architectures

Identical Architecture Topology:
Input Sequence (None, 250) → Embedding Layer (10000, 64) → Recurrent Layer (64 units) → Dropout (0.3) → Dense (32, ReLU) → Output Dense (1, Sigmoid)

To isolate the recurrent mechanism as the sole independent variable, both the Simple RNN and LSTM models employ the exact same embedding dimensionality (64), hidden capacity (64 units), dropout probability (0.3), dense projection (32 units), Adam optimizer (\(\alpha = 0.001\)), and binary crossentropy loss.

3. Mathematical Derivations: Vanishing Gradient vs. CEC

Simple RNN: Backpropagation Through Time (BPTT)

Let the recurrence equation be:

h_t = \tanh(W_{hh} h_{t-1} + W_{xh} x_t + b_h)

The gradient of the final loss \( L \) with respect to the initial hidden state \( h_1 \) expands via the chain rule as a product of Jacobian matrices:

\frac{\partial L}{\partial h_1} = \frac{\partial L}{\partial h_T} \prod_{k=2}^T \frac{\partial h_k}{\partial h_{k-1}}

Since \( \frac{\partial h_k}{\partial h_{k-1}} = \text{diag}(1 - h_k^2) W_{hh}^T \), and \( \tanh'(z) \in (0, 1] \), as sequence length \( T \) grows, the repeated matrix product causes the gradient to decay exponentially towards zero (\( \lambda_{\max}(W_{hh}) < 1 \)). Consequently, weight updates reflect only the most recent tokens.

LSTM: Constant Error Carousel (CEC)

Hochreiter & Schmidhuber (1997) resolved this by introducing the additive cell state \( C_t \):

C_t = f_t \odot C_{t-1} + i_t \odot \tilde{C}_t

The gradient flow directly along the cell state is:

\frac{\partial C_t}{\partial C_{t-1}} = f_t

When the forget gate \( f_t \approx 1 \), the error propagates through arbitrary temporal intervals without exponential attenuation, creating a constant error conveyor belt that prevents vanishing gradients.

4. NLP Preprocessing & The Negation Rule

Standard NLP pipelines frequently apply blanket stopword deletion, inadvertently removing critical polarity modifiers such as not, no, never, neither, hardly, and cannot. In our pipeline, an explicit whitelist preserves all negation tokens. Words are transformed through lowercase conversion, HTML tag removal, regex contraction expansion (e.g. "can't" → "can not"), whitespace normalization, training-only vocabulary fitting, and post-padding to 250 tokens.

6. Controlled Long-Term Dependency Experiments

Rather than relying solely on global test set accuracy, the study executes 5 controlled probe suites:

  1. Sequence Length Scaling: Evaluates accuracy and training latency across 50, 100, 250, and 500 token thresholds.
  2. Early Sentiment Probes: Sentiment markers located at indices 1-5 followed by 25+ neutral words to measure backward gradient preservation.
  3. Late Sentiment Probes: Sentiment markers placed at the end to confirm short-term recency bias.
  4. Long-Distance Negation: Measures the model's capability to invert sentiment when "not" is separated from "good" by up to 20 tokens.
  5. Distance Gap Scan: Parametrically increases filler words from 1 to 25 to graph the degradation boundary.

In practice, early tokens exert near-zero influence on the final hidden state after 10-20 steps.

Because updates to the cell state are additive (\( C_t = f_t \odot C_{t-1} + i_t \odot \tilde{C}_t \)), the partial derivative \( \frac{\partial C_t}{\partial C_{t-1}} = f_t \). Computational complexity and memory footprint. Simple RNN has 1 hidden state matrix computation per step, whereas LSTM has 4 (Forget, Input, Candidate, Output gates), requiring ~4x more FLOPs and weights. For short sequences or edge devices where latency and RAM are constrained, Simple RNN is significantly faster.
